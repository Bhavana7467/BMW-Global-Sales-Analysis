# BMW Global Sales Analysis Dashboard

## 📊 Project Overview

This project presents an interactive BMW Global Sales Analysis Dashboard developed using Microsoft Excel.

The dashboard provides insights into BMW sales performance, revenue, models, regions, monthly trends, EV growth, and fuel price relationships.

## 🎯 Objectives

- Analyze BMW global sales performance
- Identify top-selling BMW models
- Compare sales across regions
- Analyze monthly sales trends
- Study EV growth over the years
- Analyze the relationship between fuel prices and sales
- Create an interactive Excel dashboard

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Analysis
- Data Visualization
- Interactive Dashboard

## 📈 Key Insights

- Total Units Sold: 24.51M+
- Total Revenue: €1.57T+
- Average Car Price: €63.85K
- Regional sales comparison
- Monthly sales trend analysis
- EV growth trend analysis
- Revenue by BMW model
- Fuel Price vs Sales analysis
